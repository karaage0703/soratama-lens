# Soratama Lens

写真・動画を宙玉レンズ風に加工するWebアプリ。WebGLで端末内処理し、ファイルのアップロードは不要です。

**[ブラウザで開く](https://karaage0703.github.io/soratama-lens/)**

## 使い方

1. 画像・動画を開く
2. 宙玉の大きさ・位置・歪み・背景ぼかしを調整
3. PNGまたは動画で保存

MP4／WebM保存と、エフェクトをかけずに形式だけ変換する操作に対応しています。音声付きMP4の対応はブラウザによります。
