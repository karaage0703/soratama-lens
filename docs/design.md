# Soratama Lens
写真・動画を選び、宙玉の形と背景を調整して保存するための編集画面。
暗い写真編集室を基調とし、プレビューを最大の視覚要素にする。
暗色面・細い境界・編集ツールとしての情報密度を優先する。
ブランド名や専用フォントは流用せず、システムフォント、暖色のアクセントを使う。
デスクトップは左に大きいキャンバス、右に幅300pxの調整パネル。モバイルは縦積み。
12/14/16pxの本文、32pxのタイトル、余白8/16/24/32px、角丸6px。
操作: デモ→ファイル選択→調整→保存→別ファイル選択。両画面幅で同じ経路。
ネイティブbutton/input/select、ラベル、見えるfocus、disabled、aria-liveによる状態通知。
品質参照: https://github.com/Nutlope/hallmark および https://design.digital.go.jp/dads/
